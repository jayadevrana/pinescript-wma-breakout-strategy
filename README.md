# Pine Script WMA Breakout Strategy

A clean TradingView Pine Script strategy project published by Jayadev Rana for traders who want practical examples of WMA breakout, target percentage, fixed stop loss.

## Overview

This repository contains a public Pine Script source file saved as `wma_breakout_strategy.txt` so it opens easily on GitHub and can be copied into TradingView.

The script focuses on WMA breakout, target percentage, fixed stop loss, trailing stop option. It is useful for traders, students, and developers studying custom Pine Script workflows, TradingView chart tools, strategy logic, alerts, and technical-analysis automation.

For custom TradingView Pine Script development, visit https://jayadevrana.com.

## Strategy Description

Pine Script WMA Breakout Strategy is designed to make a specific TradingView workflow easier to inspect and reuse: WMA breakout, target percentage, fixed stop loss, trailing stop option. The script keeps the logic visible in one `.txt` file, which makes it helpful for reviewing how conditions, plots, labels, sessions, filters, or strategy orders are structured.

This project adds a professional public example to the Jayadev Rana Pine Script portfolio. It is practical enough to study on real charts, but the README avoids unsupported performance claims. ## How to Use in TradingView

1. Open TradingView.
2. Go to the Pine Editor.
3. Copy the code from `wma_breakout_strategy.txt`.
4. Paste it into the Pine Editor.
5. Save the script.
6. Add it to your chart.
7. Configure the available inputs.
8. If alerts are included in the script, create alerts from TradingView's alert dialog.
